# 로드뷰 영상 레퍼런스 분석

자료: 로드뷰 화면 녹화 191초, 3초 간격 64프레임 (원본 영상·프레임은 저장소에 넣지 않음).
브라우저 UI·미니맵·라벨·컨트롤은 분석에서 뺐다.

## 결론: 새 맵이 아니라 기존 캠퍼스 맵의 검증·보완
- 영상은 이미 구현된 캠퍼스와 같은 장소다.
  - 미니맵 라벨에 '영전1길', 기숙사, 태초관 등 기존 데이터의 건물 이름이 나온다.
  - 긴 3층 건물, 빨간 부스, 유리 입면과 캔틸레버 캐노피, 녹슨 외장 건물이 기존 모델과 일치한다.
- 기존 맵의 좌표계와 스케일을 그대로 쓴다.
  - 좌표: x 동쪽, y 북쪽, 단위 m.
  - 건물 외곽선·층수는 브이월드, 도로는 OSM·브이월드 중심선, 고도는 SRTM이다.
- 그래서 영상 프레임 간 이동량으로 거리를 다시 재지 않았다. 파노라마 이동은 불연속이라 거리로 쓸 수 없다.
- 이 영상으로는 **빠진 요소를 찾고 상대 위치를 확인하는 데만** 썼다.

## 이번에 반영한 것 (모두 `src/data/details.js` 한 곳에서 조정)
- `PROPS`
  - 공중전화 부스 2개를 더해 3개가 나란히 서게 했다.
  - 깃대 3개를 추가했다 (`flag` 소품, 8 m).
- `POLE_ROADS` (새 설정): 전봇대·전선을 세울 도로, 간격, 도로 중심선에서의 거리. 영전1길을 추가했다.
- 바위 화단 소품: 큰 바위 하나 → 연석 안의 돌 무더기와 관목.
- 부스와 바위 화단은 "도로 위 소품 자동 제거" 필터에서 뺐다. 로드뷰에서 연석 바로 옆으로 확인했기 때문이다.

## 검증
- 로컬 서버에서 013 시점 근처로 카메라를 옮겨 화면을 찍어 비교했다.
  - 바위 화단 → 부스 3개 → 뒤쪽 건물 순서와 배치가 영상과 맞는다.
- 부스·깃대·전봇대에 충돌체가 생기는 것을 확인했다.
